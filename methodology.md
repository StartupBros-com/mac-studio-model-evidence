# Methodology

Official evidence is a reviewed projection from a private evaluation lab. Each dataset row identifies the model, runtime, quantization, hardware profile, run dates, workload coverage, repeat count, method, and evidence identifiers. Rows lacking required context are not claim-ready.

## Reproduction

Use the published dataset and report to select the stated model, runtime, quantization, hardware, and workload method. Community runs must declare contributor identity, evidence provenance, hardware, runtime, compatibility with the published method, and result summary. Public artifacts do not include private prompts, corpora, paths, topology, or control-plane code.

Community evidence remains separate from official recommendations, has no review deadline, and never enters official rankings.

## Attribution convention

Report footer links use `utm_source=<destination site>`, `utm_medium=report`, and `utm_campaign=<release-id>`. The attribution log separates direct outcomes, sales and qualified inquiries, from leading indicators such as stars, followers, citations, contributors, and referred visits.
